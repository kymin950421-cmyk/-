## 직접 확인한 공식 원본

- [신한카드 성남시 아동수당 포인트 가맹점 조회](https://www.shinhancard.com/mob/MOBFM204N/MOBFM204R11.shc)
- 이 페이지의 공개 스크립트: `/mob/static/js/mobfm204/MOBFM204R11.js`
- 실제 조회 응답: `/mob/MOBFM204N/MOBFM204R1101.ajax`
- `mbw_json.mchtList`는 MCT_N(가맹점 ID), MCT_NM(이름), MCT_AR(주소), MCT_RY_NM(업종), MCT_XC_VL/MCT_YC_VL(원본 좌표) 등 열 배열을 반환하며, `NXT_QY_KEY`로 다음 페이지를 제공합니다.
- 직접 HTTPS 요청으로 응답을 확인했습니다. 응답에는 원본 명부 기준일과 좌표계 선언이 없어 이를 임의로 만들어 넣지 않습니다.

## 우리 데이터 구성 원칙

다른 개발자의 JSON을 재복제하는 대신, 세 구의 공식 조회를 자연스러운 다음 페이지 순서로 직접 수집합니다. 임의의 가맹점 ID나 페이지 커서를 만들어 건너뛰지 않습니다. 구별 작업 3개, 각 요청 사이 최소 450ms 대기, 제한된 재시도와 중간 저장을 사용합니다. 원본 스크립트는 폼 인코딩 방식만 참고했으며, 다른 저장소의 수집 코드를 실행하거나 복사하지 않았습니다.

수집이 모두 완료된 경우에만 공개용 스냅샷을 생성합니다. 중복 ID·페이지 반복·구 누락·불완전한 열·의심스러운 건수 감소는 교체를 중단시킵니다. 전화번호 등 앱에서 사용하지 않는 열은 공개 스냅샷에 넣지 않습니다. 기존 가공 좌표를 재사용하지 않습니다.

원본 좌표는 pyproj의 EPSG 정의로 5174→4326 변환합니다. EPSG:5174는 다른 프로젝트의 단서를 판교 현대백화점 주소와 좌표로 대조한 해석이며 신한카드의 공식 좌표계 선언으로 표현하지 않습니다. 표본에서 5174는 판교역로146번길 20 부근을 가리키지만 5181/2097은 각각 수백 미터 차이가 났습니다. 중간 수집본 중 기존 자료와 이름·주소가 정확히 일치하는 315곳을 대조했을 때, EPSG:5174 변환과 기존 좌표의 차이는 중앙값 2.4m였고 293곳이 100m 이내였습니다. 대안인 5181/2097은 중앙값 312.9m/254.0m였습니다. 이 비교의 기존 좌표도 가공 자료여서 절대적인 실측 기준은 아닙니다. 모든 매장의 출입구 정확도를 검증한 것은 아닙니다. 0·범위 외 좌표는 목록에만 남기고 지도에서 제외합니다.

## 이용 조건과 광고

공개 조회 가능 여부는 데이터의 상업적 재배포 허락을 의미하지 않습니다. 신한카드/제공기관의 이용 조건 및 광고 수익화를 위한 재이용 가능 범위는 별도 확인이 필요합니다. 공공데이터포털의 실제 파일·기준일·공공누리 유형을 확인해 적합한 원본이 확보된다면 그것도 후보가 됩니다. 성남사랑상품권 가맹점은 아동수당 가맹점과 동일하지 않아 혼합하지 않습니다.
